# i18n Expansion Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Take Lus from two partly-parallel locale files to a governed six-language i18n system with parity enforced by a test, and make the agent lane localizable beyond the two languages its envelope currently hard-codes.

**Architecture:** `he.json` is the source of truth; every other locale is measured against it by an automated parity guard. Locales ship behind an allowlist so an incomplete language is never selectable. The Python agent envelope stops being the localization mechanism — agents return a stable `ErrorInfo.Code`, and the frontend localizes by code, with the envelope's bilingual strings kept only as a last-resort fallback.

**Tech Stack:** `@ngx-translate/core` 15 (→ 17 after plan 07), Angular 20, xUnit, pytest, Node scripts for the parity guard.

**Spec:** [`docs/superpowers/specs/2026-08-18-ai-builders-port-design.md`](../specs/2026-08-18-ai-builders-port-design.md)

## Global Constraints

- **`he.json` is the source of truth.** Hebrew is the domain's primary language; every locale is diffed against it, never against `en`.
- **No hardcoded user-facing strings.** Enforced by a guard test, not by review.
- **An incomplete locale is not selectable.** Shipping a 70%-translated language is worse than not shipping it — the user gets a bilingual UI with no way back.
- **Agents localize by code, not by string.** `ErrorInfo.Code` is the contract; `UserMessage`/`UserMessageEn` are fallback only.
- **RTL is not a language property.** `he` and `ar` are RTL; the direction switch is driven by a locale registry, not by an `if lang === 'he'`.
- Backend tests in `src/Lus.Api.Tests`; frontend guard runs in `npm test` and in CI.

## Starting state (verified 2026-08-18)

| | Lus | ArmyLuz (port source) |
|---|---|---|
| Locales | `he`, `en` | `he`, `en`, `ar`, `es`, `fr`, `ru` |
| Keys (he) | **202** | **6902** |

| Library | `@ngx-translate/core` ^15 | ^15 |
| Files using translate | 14 | most |

**Two findings that shape this plan:**

1. **ArmyLuz's own locale set is incomplete.** Copying `es`/`fr`/`ru` wholesale imports 197–521
   missing keys as technical debt on day one. They come across, but gated (Task 4).
2. **The agent envelope is bilingual by construction.** `runner.py` emits
   `ErrorInfo: {Code, UserMessage(he), UserMessageEn}` — exactly two languages. Adding four more by
   widening the envelope would mean every agent carrying six translations of every error. It
   doesn't scale, and it puts translation in the wrong layer. Task 5 fixes the layering instead.

```typescript
import he from '../../../../assets/i18n/he.json';
import en from '../../../../assets/i18n/en.json';

type Json = { [k: string]: unknown };

function flatten(obj: Json, prefix = ''): Record<string, string> {
  const out: Record<string, string> = {};
  for (const [k, v] of Object.entries(obj)) {
    const key = prefix ? `${prefix}.${k}` : k;
    if (v !== null && typeof v === 'object' && !Array.isArray(v)) {
      Object.assign(out, flatten(v as Json, key));
    } else {
      out[key] = String(v);
    }
  }
  return out;
}

describe('i18n parity', () => {
  const source = flatten(he as Json);

  it('he.json is non-empty and is the source of truth', () => {
    expect(Object.keys(source).length).toBeGreaterThan(100);
  });

  it('en.json has every key he.json has', () => {
    const target = flatten(en as Json);
    const missing = Object.keys(source).filter(k => !(k in target));
    expect(missing).withContext(`missing in en: ${missing.join(', ')}`).toEqual([]);
  });

  it('en.json has no keys he.json lacks', () => {
    const target = flatten(en as Json);
    const extra = Object.keys(target).filter(k => !(k in source));
    expect(extra).withContext(`orphaned in en: ${extra.join(', ')}`).toEqual([]);
  });

  it('no locale value is an empty string', () => {
    const empties = Object.entries(flatten(en as Json))
      .filter(([, v]) => v.trim() === '')
      .map(([k]) => k);
    expect(empties).withContext(`empty values in en: ${empties.join(', ')}`).toEqual([]);
  });
});
```

```javascript
#!/usr/bin/env node
/**
 * i18n parity guard. he.json is the source of truth — every other locale is
 * measured against it, never against en.
 *
 *   node tools/i18n-parity.mjs           → exit 1 on any gap in an ENFORCED locale
 *   node tools/i18n-parity.mjs --report  → print coverage for every locale, always exit 0
 *
 * Enforced locales are listed in locales.config.json. A locale that is present
 * but not enforced is a work in progress: reported, never allowed to fail CI,
 * and never selectable in the UI (see language.service.ts).
 */
import { readFileSync, readdirSync } from 'node:fs';
import { join, dirname, basename } from 'node:path';
import { fileURLToPath } from 'node:url';

const here = dirname(fileURLToPath(import.meta.url));
const i18nDir = join(here, '..', 'src', 'assets', 'i18n');
const configPath = join(here, '..', 'src', 'assets', 'i18n', 'locales.config.json');

const reportOnly = process.argv.includes('--report');

function flatten(obj, prefix = '') {
  const out = {};
  for (const [k, v] of Object.entries(obj)) {
    const key = prefix ? `${prefix}.${k}` : k;
    if (v !== null && typeof v === 'object' && !Array.isArray(v)) {
      Object.assign(out, flatten(v, key));
    } else {
      out[key] = String(v);
    }
  }
  return out;
}

const load = (f) => flatten(JSON.parse(readFileSync(join(i18nDir, f), 'utf8')));

const config = JSON.parse(readFileSync(configPath, 'utf8'));
const enforced = new Set(config.enforced);

const source = load('he.json');
const sourceKeys = Object.keys(source);

let failed = false;
const rows = [];

for (const file of readdirSync(i18nDir).filter(f => f.endsWith('.json') && f !== 'locales.config.json')) {
  const code = basename(file, '.json');
  if (code === 'he') continue;

  const target = load(file);
  const missing = sourceKeys.filter(k => !(k in target));
  const extra = Object.keys(target).filter(k => !(k in source));
  const empty = Object.entries(target).filter(([, v]) => v.trim() === '').map(([k]) => k);
  const coverage = ((sourceKeys.length - missing.length) / sourceKeys.length * 100).toFixed(1);

  rows.push({ code, coverage, missing, extra, empty, enforced: enforced.has(code) });

  if (enforced.has(code) && !reportOnly && (missing.length || extra.length || empty.length)) {
    failed = true;
  }
}

console.log(`source: he.json — ${sourceKeys.length} keys\n`);
for (const r of rows) {
  const tag = r.enforced ? 'ENFORCED' : 'wip     ';
  console.log(`${tag}  ${r.code.padEnd(4)} ${r.coverage.padStart(6)}%  ` +
              `missing=${r.missing.length} extra=${r.extra.length} empty=${r.empty.length}`);
  if (r.enforced && !reportOnly) {
    for (const k of r.missing.slice(0, 20)) console.log(`             MISSING ${k}`);
    for (const k of r.extra.slice(0, 20))   console.log(`             ORPHAN  ${k}`);
    for (const k of r.empty.slice(0, 20))   console.log(`             EMPTY   ${k}`);
  }
}

if (failed) {
  console.error('\ni18n parity FAILED for an enforced locale.');
  process.exit(1);
}
console.log('\ni18n parity ok.');
```

Create `src/Lus.UI/tools/i18n-seed.mjs`:

```javascript
#!/usr/bin/env node
/**
 * Seed a Lus locale file from ArmyLuz's translations.
 *
 *   node tools/i18n-seed.mjs ar /path/to/ArmyLuz.UI
 *
 * Takes Lus's he.json key set as the shape, and for each key looks for the SAME
 * key path in ArmyLuz's he.json. Where the Hebrew source strings match exactly,
 * ArmyLuz's translation for the target locale is reused; otherwise the key is
 * emitted with an empty string so the parity report counts it as untranslated.
 *
 * Matching on the Hebrew VALUE, not just the key path, is the point: identical
 * key paths across two products can mean different things, and a wrong
 * translation is worse than a missing one.
 */
import { readFileSync, writeFileSync } from 'node:fs';
import { join, dirname } from 'node:path';
import { fileURLToPath } from 'node:url';

const [, , locale, azRoot] = process.argv;
if (!locale || !azRoot) {
  console.error('usage: node tools/i18n-seed.mjs <locale> <path-to-ArmyLuz.UI>');
  process.exit(1);
}

const here = dirname(fileURLToPath(import.meta.url));
const lusI18n = join(here, '..', 'src', 'assets', 'i18n');
const azI18n = join(azRoot, 'src', 'assets', 'i18n');

const flatten = (obj, prefix = '') => {
  const out = {};
  for (const [k, v] of Object.entries(obj)) {
    const key = prefix ? `${prefix}.${k}` : k;
    if (v !== null && typeof v === 'object' && !Array.isArray(v)) Object.assign(out, flatten(v, key));
    else out[key] = String(v);
  }
  return out;
};

const unflatten = (flat) => {
  const out = {};
  for (const [path, value] of Object.entries(flat)) {
    const parts = path.split('.');
    let node = out;
    parts.forEach((p, i) => {
      if (i === parts.length - 1) node[p] = value;
      else node = (node[p] ??= {});
    });
  }
  return out;
};

const read = (p) => JSON.parse(readFileSync(p, 'utf8'));

const lusHe = flatten(read(join(lusI18n, 'he.json')));
const azHe = flatten(read(join(azI18n, 'he.json')));
const azTarget = flatten(read(join(azI18n, `${locale}.json`)));

let reused = 0;
const seeded = {};
for (const [key, heValue] of Object.entries(lusHe)) {
  const azHeValue = azHe[key];
  if (azHeValue !== undefined && azHeValue.trim() === heValue.trim() && azTarget[key]) {
    seeded[key] = azTarget[key];
    reused++;
  } else {
    seeded[key] = '';
  }
}

writeFileSync(join(lusI18n, `${locale}.json`),
              JSON.stringify(unflatten(seeded), null, 2) + '\n', 'utf8');

const total = Object.keys(lusHe).length;
console.log(`${locale}: ${reused}/${total} reused from ArmyLuz (${(reused / total * 100).toFixed(1)}%), ` +
            `${total - reused} left empty`);
```

```python
RUNNER = os.path.join(SCRIPTS_ROOT, "agents", "runner.py")

# agentErrors.<code> key in every enforced locale.
KNOWN_CODES = {
    "unknown_agent",
    "invalid_input",
    "schema_validation_failed",
    "agent_error",
}


def _run(agent, payload):
    return subprocess.run(
```

```csharp
using System.Text.Json;
using FluentAssertions;
using Xunit;

namespace Lus.Api.Tests.Builders;

/// <summary>
/// Every failure code the system can produce must have a translation key in every
/// ENFORCED locale. A missing key means a user sees a raw code.
/// </summary>
public class AgentErrorCodeTests
{
    private static readonly string[] AllFailureCodes =
    {
        // from runner.py ERROR_CODES
        "unknown_agent", "invalid_input", "schema_validation_failed", "agent_error",
        // from BuilderAgentClient
        "envelope_unparseable", "empty_result",
        // client-side catch-all
        "unknown",
    };

    private static string RepoRoot()
    {
        var dir = new DirectoryInfo(AppContext.BaseDirectory);
        while (dir is not null && !Directory.Exists(Path.Combine(dir.FullName, "PythonScripts")))
            dir = dir.Parent;
        return dir!.FullName;
    }

    private static string[] EnforcedLocales()
    {
        var configPath = Path.Combine(RepoRoot(), "src", "Lus.UI", "src", "assets", "i18n",
                                      "locales.config.json");
        using var doc = JsonDocument.Parse(File.ReadAllText(configPath));
        var enforced = doc.RootElement.GetProperty("enforced")
                          .EnumerateArray().Select(e => e.GetString()!).ToList();
        enforced.Add(doc.RootElement.GetProperty("source").GetString()!);
        return enforced.ToArray();
    }

    [Fact]
    public void Every_failure_code_has_a_translation_in_every_enforced_locale()
    {
        var missing = new List<string>();

        foreach (var locale in EnforcedLocales())
        {
            var path = Path.Combine(RepoRoot(), "src", "Lus.UI", "src", "assets", "i18n",
                                    $"{locale}.json");
            using var doc = JsonDocument.Parse(File.ReadAllText(path));

            if (!doc.RootElement.TryGetProperty("agentErrors", out var errors))
            {
                missing.Add($"{locale}: no agentErrors section at all");
                continue;
            }

            foreach (var code in AllFailureCodes)
            {
                if (!errors.TryGetProperty(code, out var value) ||
                    string.IsNullOrWhiteSpace(value.GetString()))
                {
                    missing.Add($"{locale}.agentErrors.{code}");
                }
            }
        }

        missing.Should().BeEmpty("every failure code must be localized in every enforced locale");
    }

    [Fact]
    public void The_csharp_code_list_matches_the_python_vocabulary()
    {
        // Hand-synced lists drift. Read the Python source and compare.
        var runner = File.ReadAllText(Path.Combine(RepoRoot(), "PythonScripts", "agents", "runner.py"));
        var block = runner[runner.IndexOf("ERROR_CODES = (", StringComparison.Ordinal)..];
        block = block[..block.IndexOf(')', StringComparison.Ordinal)];

        var pythonCodes = block.Split('"')
                               .Where((_, i) => i % 2 == 1)
                               .ToHashSet();

        var runnerCodesInThisTest = new[]
            { "unknown_agent", "invalid_input", "schema_validation_failed", "agent_error" }
            .ToHashSet();

        pythonCodes.Should().BeEquivalentTo(runnerCodesInThisTest,
            "runner.py ERROR_CODES and this test's list must not drift");
    }
}
```

```markdown
# Internationalization

## The rules

1. **`he.json` is the source of truth.** Every locale is diffed against Hebrew, never against
   English. `tools/i18n-parity.mjs` enforces it.
2. **A locale ships before it is complete, but is not selectable until it is.**
   `src/assets/i18n/locales.config.json` has two independent gates:
   - `enforced` — CI fails on any gap. Currently `en`.
   - `enabled` — the language picker offers it. Currently `he`, `en`.
   Promote a locale by moving it into BOTH lists in one commit, once
   `npm run i18n:report` shows 100%.
3. **Direction comes from the registry, not from the language code.** `he` and `ar` are both RTL.
   `LanguageService.direction(code)` is the only place that decides.
4. **Agent failures localize by code.** `runner.py` exports `ERROR_CODES`; the frontend renders
   `agentErrors.<code>`. The envelope's bilingual strings are a fallback, not the display path.
   Adding a code means adding the key to every enforced locale in the same commit.

## Adding a key

1. Add it to `he.json`.
2. Add it to every locale in `enforced`.
3. `npm run i18n:check`.

## Adding a locale

1. `node tools/i18n-seed.mjs <code> /path/to/ArmyLuz.UI` — seeds from ArmyLuz where the Hebrew
   source string matches exactly, empty otherwise.
2. Add it to `locales` in `locales.config.json` with the correct `dir` and `enabled: false`.
3. Translate until `npm run i18n:report` shows 100%.
4. Move it into `enforced` and set `enabled: true`.

## Current state

| Locale | Dir | Enforced | Enabled |
|---|---|---|---|
| he | rtl | source | yes |
| en | ltr | yes | yes |
| ar | **rtl** | no | no |
| es | ltr | no | no |
| fr | ltr | no | no |
| ru | ltr | no | no |

Run `npm run i18n:report` for live coverage figures.
```
